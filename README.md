# سيارتي

سجل الوقود والصيانة والمصاريف لسيارتك — بدون إعلانات، يعمل بدون إنترنت، وبياناتك على جهازك فقط.

- تعبئة الوقود وحساب الاستهلاك (من خزان ممتلئ إلى ممتلئ)
- الصيانة والمصاريف والدخل، مع أصناف قابلة للتعديل
- تذكيرات صيانة بالمسافة أو المدة أو تاريخ محدد، مع إضافتها لتقويم الهاتف
- تقارير شهرية وتكلفة الكيلومتر
- نسخ احتياطي إلى Google Drive عبر قائمة المشاركة، وتصدير CSV

## التثبيت
افتح الرابط من الجوال ثم: **Android (Chrome):** ⋮ ← تثبيت التطبيق. **iPhone (Safari):** مشاركة ← إضافة إلى الشاشة الرئيسية.

## النشر
تطبيق ثابت (HTML/CSS/JS) — يعمل على GitHub Pages مباشرة من فرع `main`.
